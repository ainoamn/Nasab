## التشغيل المحلي

### المتطلبات

- Node.js 20+
- npm

### الخطوات

```bash
cd app
npm install
cp .env.example .env
# عدّل .env حسب الحاجة (انظر app/.env.example)
npm run db:push
npm run dev
```

يفتح التطبيق على: **http://localhost:5173**

### دخول التطوير المحلي

عند تفعيل `DEV_LOCAL_AUTH=true` في `.env`:

| الحقل | القيمة الافتراضية |
|-------|-------------------|
| المستخدم | `admin` |
| كلمة المرور | `admin123` |

> هذا الحساب يحصل على دور **مشرف (admin)** — للتطوير فقط، ويُعطّل تلقائياً في الإنتاج.

### أوامر مفيدة

```bash
npm run dev          # خادم التطوير
npm run build        # بناء الإنتاج
npm run start        # تشغيل الإنتاج (بعد build)
npm run check        # فحص TypeScript
npm run db:push      # تطبيق schema على قاعدة البيانات
npm run db:generate  # توليد migrations
npm run db:migrate   # تشغيل migrations
```

## الميزات الرئيسية

### 1. شجرة العائلة

- إنشاء أشجار متعددة لكل مستخدم
- إضافة وتعديل الأفراد (اسم، كنية، لقب، تواريخ، مكان، صورة، ملاحظات)
- **ربط القرابة**: ابن، بنت، أخ، أخت، زوج/زوجة، فرع خارجي
- **فصل الربط**: من بطاقة الشخص → قسم «الروابط العائلية» → زر «فصل الربط» (أب/أم/زوج/أبناء) دون حذف الشخص
- مخطط شجرة تفاعلي مع:
  - رأس موقع العائلة (غلاف + إحصائيات + نبذة)
  - أوضاع متعددة: عرض العائلة / العائلة القريبة / مخطط الأسلاف / مظهر مروحي
  - شريط مناسبات (أعياد ميلاد وذكريات زواج)
  - بحث سريع، خط زمني، زر + للإضافة، وخانات أب/أم قابلة للنقر
  - تبويب صور + تسميات قرابة في القائمة
  - بطاقات عمودية بأسلوب عائلي وخطوط متعامدة بلا أسهم
  - لوحة تفاصيل جانبية عند اختيار شخص
  - لوحة **اكتشافات** لنواقص الربط (آباء، زوجية) مع إجراءات سريعة
  - تحكم بعدد الأجيال + وضع ملء الشاشة للمخطط
- استيراد Excel جماعي
- **تصدير GEDCOM 5.5.1** للتوافق مع برامج الأنساب
- طباعة PDF عبر **13 قالباً** (نخلة، مخطوط، كتاب، ملصق، خريطة، فخذ، مناسبات، مزخرف، مروحة، شمس نسب، كلاسيكي، نسب أعمدة، تراث) مع تحديد نطاق الأجيال/الفرع
- سجل تغييرات (Audit log) لكل شجرة

### 2. الخصوصية والعرض

- مستويات خصوصية للفرد: خاص / عائلة / مرتبط / عام
- إعدادات الشجرة: إخفاء الأحياء، عرض الإناث (كامل / الاسم الأول / إخفاء)
- رؤية الشجرة: خاصة / غير مدرجة / عامة
- صفحة مشاركة عامة `/share/:id` مع فلترة الخصوصية للزوار

### 3. الأعضاء والدعوات

- أدوار: **مالك / مشرف / محرر / مشاهد**
- دعوة بالرابط مع token آمن وتاريخ انتهاء
- قبول الدعوة من `/invite/:token`

### 4. إدارة الشجرة (Dashboard)

- **إيقاف مؤقت (paused)**: عرض فقط — لا تعديل
- **أرشفة (archived)**: إخفاء كامل — المالك يستعيد من لوحة التحكم
- **حذف نهائي** للشجرة (مع تأكيد)
- إظهار/إخفاء الأشجار المؤرشفة

### 5. حذف الأفراد (Soft delete)

- حذف ناعم عبر `deletedAt` — يختفي من الشجرة والإحصائيات
- *(استرجاع الأفراد المحذوفين: غير مُنفَّذ بعد)*

### 6. حساب المستخدم `/account`

- الملف الشخصي والعنوان وبريد الفوترة
- عرض الاشتراك وتواريخ البداية/الانتهاء
- استخدام الخطة (أشجار، أفراد، حدود)
- **كود خصم** و**رمز إحالة**
- الفواتير (تحميل كسول عند فتح تبويب الدفع)

### 7. أرقام متسلسلة

| النوع | الصيغة | مثال |
|-------|--------|------|
| المستخدم | `USR-000001` | تلقائي |
| الفاتورة | `INV-000001` | عند إنشاء فاتورة |
| الإحالة | `NSB00001` | من رقم المستخدم |

### 8. الاشتراكات

| الخطة | الوصف |
|-------|-------|
| **مجانية** | حتى 500 فرد، دعوات، PDF أساسي |
| **نَسَب بلس** | أفراد بلا حدود، قوالب طباعة، أرشيف |
| **الطباعة** | طلبات طباعة حسب الحاجة |

- حساب تلقائي لـ **تاريخ بداية/انتهاء** الاشتراك حسب مدة الباقة (`periodDays`)
- **خصم التجديد** (`renewalDiscountPercent`) قابل للضبط من المشرف
- **مكافأة الإحالة**: +30 يوماً للمُحيل عند اشتراك المُدعو ودفع فاتورته

### 9. الكوبونات والخصومات

- أكواد نسبة مئوية أو مبلغ ثابت
- تنطبق على: اشتراك جديد / تجديد / الكل
- تُطبَّق عند إتمام الدفع (لا تُستهلك مسبقاً)

### 10. بوابات الدفع

| البوابة | النوع |
|---------|-------|
| **Thawani** | Checkout hosted (عُمان) |
| **Stripe** | Checkout Session |
| **PayPal** | Orders API |
| **تحويل بنكي** | تعليمات + فاتورة معلقة |
| **يدوي** | تأكيد من المشرف |

- لوحة المشرف: شبكة بطاقات بشعارات — الضغط يفتح `/admin/gateways/:slug`
- صفحة checkout: `/checkout?plan=plus`
- Webhooks: `/api/webhooks/{thawani,stripe,paypal}`

### 11. تسجيل الدخول

- **Kimi OAuth** (الأساسي)
- **Google OAuth** (اختياري — `GOOGLE_CLIENT_ID` + `GOOGLE_CLIENT_SECRET`)
- **دخول محلي** (تطوير فقط)

## قاعدة البيانات

### جداول رئيسية

- `users` — حسابات، خطة، إحالة، حظر، IP
- `trees` — أشجار + حالة (active/paused/archived)
- `persons` — أفراد + soft delete
- `relationships` — قرابة (أب/أم/زوج)
- `tree_members` — أعضاء وأدوار
- `invites` — دعوات
- `change_logs` — سجل التغييرات
- `subscription_plans` — خطط وحدود
- `invoices` — فواتير + gateway + plan
- `coupons` / `coupon_redemptions` — خصومات
- `payment_gateways` — إعدادات البوابات
- `platform_sequences` — ترقيم USR/INV
- `expenses` — مصروفات المحاسبة

### التطوير vs الإنتاج

```env
# تطوير (SQLite)
DATABASE_URL=file:./.data/dev.sqlite

# إنتاج (MySQL)
DATABASE_URL=mysql://user:pass@host:3306/nasab
```

## الاشتراكات والدفع

### تفعيل بوابة (مثال Thawani UAT)

1. `/admin/gateways` → Thawani → تفعيل
2. أدخل `publishableKey`, `secretKey`, `webhookSecret`
3. `baseUrl`: `https://uatcheckout.thawani.om/api/v1`
4. سجّل Webhook: `https://yourdomain.com/api/webhooks/thawani`

### مسار الشراء

```
/checkout?plan=plus → اختيار بوابة → دفع → /checkout/success
```

## لوحة المشرف

- إحصائيات: مستخدمون، أشجار، إيرادات، توزيع الخطط
- إدارة المستخدمين: تعديل خطة، حظر، IP التسجيل/الدخول
- خطط الاشتراك: حدود، سعر، مدة، خصم تجديد
- فواتير: إنشاء/تعديل/تأكيد يدوي (للتحويل البنكي)
- محاسبة: إيرادات، مصروفات، صافي الربح
- كوبونات وبوابات دفع

## الأمان والأرشفة

### طبقات الحماية الموجودة

- JWT في cookie `httpOnly` + `secure` (HTTPS)
- tRPC middleware: مصادقة + حظر المستخدم
- RBAC: admin على المنصة + أدوار على الشجرة
- أرشفة/إيقاف الشجرة يُطبَّق على API
- Drizzle ORM (حماية SQL injection)
- Zod للتحقق من المدخلات
- دعوات: token عشوائي + انتهاء صلاحية
- توقيع webhooks للبوابات + ربط جلسة الدفع بالفاتورة
- OAuth `state` موقّع + `ALLOWED_ORIGINS`
- Rate limiting على login / OAuth / webhooks / الدعوات
- Security headers
